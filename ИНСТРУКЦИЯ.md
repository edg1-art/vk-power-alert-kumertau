# Инструкция: уведомления об отключениях электроэнергии (Кумертау)

## Что делает бот

Каждые 5 минут GitHub (сервер GitHub, не ваш компьютер) запускает `vk_check.py`.

1. Скрипт забирает 10 последних записей сообщества
   «Город Кумертау — официальная страница администрации» (vk.com/toser_admkumertau).
2. Отбирает записи, где есть «отключение электроэнергии» (в любой форме).
3. Если в тексте есть улица из списка (по умолчанию **Авиаторов**) — ставит
   заголовок «⚡ ВАША УЛИЦА», иначе «🔔 Отключение электроэнергии».
4. Отправляет в Telegram только то, чего ещё не отправлял.
5. Запоминает номер последней записи в `state.json` и коммитит его обратно.

Ваш компьютер и интернет могут быть выключены — бот работает на GitHub.

## Состав папки

| Файл | Зачем |
|---|---|
| `vk_check.py` | сам бот (Python, без сторонних библиотек) |
| `config.json` | настройки: сообщество, слова, улицы, режим |
| `state.json` | память бота (появляется после первого запуска) |
| `.github/workflows/vk-check.yml` | расписание «каждые 5 минут» |
| `.github/workflows/telegram-diag.yml` | разовая диагностика Telegram (можно удалить) |
| `ТЕСТ-локально.bat` | проверить на ПК, ничего не отправляя |
| `ИНСТРУКЦИЯ.md` | этот файл |

## Быстрая проверка на ПК

Двойной клик по `ТЕСТ-локально.bat`. В окне будет список 10 последних записей
и пометки:

- `ОТКЛЮЧЕНИЕ` — запись про отключение электроэнергии;
- `УЛИЦА:Авиаторов` — в тексте есть ваша улица.

Ничего не отправляется и не сохраняется.

## Как поменять улицу

Откройте `config.json`:

```json
"streets": ["Авиаторов"]
```

Можно несколько: `["Авиаторов", "Ленина"]`. Регистр и «ё» не важны,
`ул.Авиаторов`, `-ул. Авиаторов` и `АВИАТОРОВ` находятся одинаково.

Режим (`street_mode`):

| Значение | Поведение |
|---|---|
| `mark` | приходят все отключения; ваша улица — с пометкой ⚡ (по умолчанию) |
| `only` | приходят **только** отключения с вашей улицей |
| `off` | приходят все, без пометок |

Чтобы «только своя улица»: поставьте `"street_mode": "only"` и сохраните файл.

## Как поменять частоту проверки

Файл `.github/workflows/vk-check.yml`, строка:

```yaml
- cron: "*/5 * * * *"
```

- `*/5` — каждые 5 минут (по умолчанию);
- `*/10` — каждые 10 минут;
- `*/30` — каждые 30 минут.

Время в файле — UTC, но для «каждые N минут» это не важно.

## Где смотреть, что бот делает

1. Откройте репозиторий на GitHub.
2. Вкладка **Actions** → слева **VK power alert**.
3. Любой запуск (самый свежий сверху) → шаг **Проверить ВК и отправить в Telegram**.
   Там видно: `ВК: получено 10 записей`, `Новых записей: 0`,
   `Отправлено уведомление по записи ...`.

Зелёная галочка — всё хорошо. Красный крестик — смотрите текст ошибки.

## Что делать, если сломалось

| Симптом | Причина | Что делать |
|---|---|---|
| `капча/проверка безопасности` | ВК не пускает серверный IP | см. «План Б» ниже |
| `Telegram отказ: chat not found` | не нажали «/start» у бота или неверный chat_id | нажать Start, обновить секрет `TELEGRAM_CHAT_ID` |
| `Telegram недоступен` | сбой сети GitHub | подождать, следующий запуск повторит |
| Расписание перестало запускаться | GitHub отключает расписание после 60 дней без активности | сделать любой коммит или нажать **Enable workflow** в Actions |
| Долго нет уведомлений | GitHub задерживает расписание (5–20 минут) | это нормально |

## План Б: официальный VK API

Если ВК начнёт отдавать капчу серверам GitHub:

1. Зайдите на https://dev.vk.com → **Мои приложения** → **Создать** →
   тип «Standalone-приложение», название любое.
2. В настройках приложения возьмите **Сервисный ключ доступа**.
3. В репозитории: **Settings** → **Secrets and variables** → **Actions** →
   **New repository secret** → имя `VK_TOKEN`, значение — ключ.
4. Ничего в коде менять не надо: при неудаче с виджетом скрипт сам
   попробует VK API.

Сервисный ключ даёт доступ только к публичным данным, к переписке — нет.

## Секреты и безопасность

- Токен Telegram хранится в **Secrets** репозитория и на странице кода не виден.
- В файлах репозитория токена нет.
- Если токен попал в чужие руки: @BotFather → `/revoke` → получить новый,
  обновить секрет `TELEGRAM_TOKEN`.

## Почему бот работает «цепочкой» (и как её перезапустить)

Штатное расписание GitHub (`schedule` каждые 5 минут) в 2026 году у новых
репозиториев часто **не срабатывает вообще** — это массовая проблема, сотни
подтверждённых жалоб. Поэтому бот работает по-другому:

- workflow **VK power alert (chain)** после запуска проверяет ВК каждые 5 минут
  в течение ~5,5 часов (64 проверки);
- в конце он сам запускает следующий такой же запуск (штатным токеном GitHub),
  и так круглосуточно;
- workflow **VK power alert** с обычным расписанием оставлен запасным — если
  GitHub когда-нибудь починит cron, он тоже начнёт срабатывать.

Запуск цепочки делается один раз вручную (уже сделан). Если понадобится снова:
Actions → **VK power alert (chain)** → **Run workflow** → зелёная кнопка.

Как проверить, что бот жив: GitHub → Actions → в списке должны быть запуски
«VK power alert (chain)» примерно каждые 5,5 часов (последний — зелёный).

Если цепочка остановилась (GitHub иногда отменяет очень долгие запуски) — бот
пришлёт в Telegram предупреждение «цепочка остановилась». Лечение: Actions →
**VK power alert (chain)** → **Run workflow**. Больше ничего не нужно.

## Как выключить бота

1. Actions → **VK power alert (chain)** → **Disable workflow**.
2. Actions → **VK power alert** → **Disable workflow** (запасной).
3. Если цепочка уже идёт — откройте её текущий запуск и нажмите **Cancel workflow**,
   иначе она доработает до конца (до 5,5 часов).
4. Actions → **Telegram diagnostics** → **Disable workflow** (или удалить файл).
