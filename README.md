# ВК-уведомления: отключения электроэнергии, Кумертау

Бот следит за официальным сообществом администрации г. Кумертау
(https://vk.com/toser_admkumertau) и присылает в Telegram новые записи
про отключение электроэнергии.

- Проверка каждые 5 минут (GitHub Actions, бесплатно, ПК может быть выключен).
- Если в записи есть улица **Авиаторов** — сообщение помечается «⚡ ВАША УЛИЦА».
- Работает без токена ВК: читает публичный виджет сообщества.

Подробная инструкция для человека: **ИНСТРУКЦИЯ.md**.

Быстрая проверка на ПК: запустить `ТЕСТ-локально.bat` (ничего не отправляет).

Настройки — `config.json`:

| Параметр | Значение | Смысл |
|---|---|---|
| `group_id` | `11784072` | id сообщества (без минуса) |
| `keywords_all` | `["электроэнерг"]` | обязательные куски текста |
| `keywords_any` | `["тключен"]` | хотя бы один из кусков |
| `streets` | `["Авиаторов"]` | улицы для пометки |
| `street_mode` | `mark` | `mark` — все + пометка; `only` — только своя улица; `off` — без пометок |

Секреты репозитория: `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`.
Необязательный `VK_TOKEN` — запасной путь через официальный VK API.
